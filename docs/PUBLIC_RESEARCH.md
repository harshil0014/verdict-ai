# Public evidence research

Paste a public URL or use **Find more evidence** to discover sources. Evidence submissions can also trigger collection of supported public references. VERDICT retrieves accessible HTML and PDF content and stores provenance for the preserved snapshot. Search results and model summaries are leads. Evidence citations point to actual preserved passages.

Discovery uses documented keyless Tavily, Wikimedia and Crossref endpoints. Google URL Context is optional for public URLs. Google Search grounding defaults off. Supported neutral citations can be used to locate an original publisher when the initial tribunal source blocks access. A current page alone does not establish a past policy.

Retrieval uses DNS validation, pinned public destinations, bounded redirects and response limits. Private or credential-bearing URLs are rejected. A failed lookup preserves the original reference and reports the failure. [Security controls](SECURITY.md)
