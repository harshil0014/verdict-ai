## Draft description

**VERDICT — The Missing Witness**

Payment disputes begin with conflicting stories and incomplete records. A delivery scan may exist without showing whether the parcel reached the right building. A conventional rebuttal assistant can make the available argument more persuasive; VERDICT asks what new evidence would actually distinguish the explanations.

VERDICT reconstructs a source-linked case, compares reported claims, identifies a targeted witness, accepts a restricted response and updates the investigation. It supports either party when the evidence warrants it and preserves uncertainty when no defensible conclusion exists. A human reviews every recommendation; sandbox PayPal actions are separated from model reasoning by current-state and exact-payload approval checks.

The working build uses React Flow, FastAPI, SQLite, a private Supabase snapshot mirror and Gemini. PayPal OAuth and dispute listing are verified. The account currently has no eligible dispute, so evidence submission and webhook delivery are implemented with contract tests but are not claimed as completed sandbox lifecycle demonstrations. The centerpiece uses labeled fictional evidence with actual model calls and actual state changes.
